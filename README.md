# Student Performance & Attendance Dashboard

## Project Overview
This project analyzes student academic performance and attendance using Python, Oracle SQL, and Microsoft Power BI.

It uses a dataset of 30 students to identify academic trends, evaluate attendance, calculate grades, and visualize student performance.

## Technologies Used
- Python
- Pandas
- Oracle SQL
- PL/SQL
- Microsoft Power BI
- GitHub

## Project Features
- Student-wise total and average marks
- Subject-wise performance analysis
- Grade calculation and distribution
- Attendance percentage and eligibility analysis
- Student ranking and Top 5 performers
- Class-wise performance comparison
- Interactive Power BI dashboard

## Dataset
The dataset contains:
- Student ID and Name
- Class and Section
- Marks in five subjects
- Classes held and classes attended

## Dashboard Preview
The Power BI dashboard presents key performance indicators, subject averages, grade distribution, attendance eligibility, top-performing students, and class-wise analysis.

## Project Files
- `student_performance_dashboard.py` – Python analysis
- `student_performance_data.csv` – Dataset
- `student_performance_queries.sql` – Oracle SQL queries
- `Student_Performance_Dashboard.pbix` – Power BI dashboard
- `05_Final_Dashboard.png` – Dashboard screenshot

## Conclusion
This project demonstrates how Python, SQL, and Power BI can be used together to analyze student performance and attendance and present meaningful insights through data visualization.
